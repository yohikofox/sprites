# Pokémon Let's Go Pikachu/Eevee Models

This directory contains sprites and models for Pokémon exclusive to or featured in Pokémon Let's Go Pikachu and Let's Go Eevee.

## Source

Models and sprites are sourced from Project Pokémon:
- [LGPE Models Documentation](https://projectpokemon.org/home/docs/spriteindex_148/lgpe-models-r111/)

## Organization

Files are organized into subdirectories by sprite type:
- `front/` - Front-facing sprites
- `back/` - Back-facing sprites
- `shiny-front/` - Shiny variant front-facing sprites
- `shiny-back/` - Shiny variant back-facing sprites

All files follow the naming convention: `{pokemon_number}_{pokemon_name}.gif`

## Currently Available

- **#808 Meltan** - All variants (front, back, shiny-front, shiny-back)
- **#809 Melmetal** - All variants (front, back, shiny-front, shiny-back)

## Notes

- Let's Go games feature updated models and special Partner Pokémon (Pikachu/Eevee) with unique appearances
- Some Pokémon have Let's Go-specific variants or forms
- These sprites are exclusive to the Let's Go series and represent Meltan and Melmetal, which debuted in Pokémon GO and Let's Go
